Security Policy
Supported Versions

Blumebyte HR is an actively maintained cloud based Human Resource management platform. Security updates are provided for the latest production versions listed below.

Version	Supported
Latest Production (6.x)	✅
5.x LTS	✅
4.x Legacy	⚠️ Limited support
Below 4.x	❌ Not supported

We strongly recommend upgrading to the latest supported release to receive security fixes and improvements.

Reporting a Vulnerability

At Blumebyte, security is a priority. We appreciate responsible disclosure from security researchers, developers, and users.

If you discover a vulnerability in Blumebyte HR, please report it privately.

How to report

Send details to:

security@blumebyte.com

Include:

• description of the issue
• steps to reproduce
• affected version
• possible impact
• screenshots or proof of concept if available

Please do not open public GitHub issues for security vulnerabilities.

What happens after you report

Once a vulnerability is submitted:

You will receive acknowledgement within 3 to 5 business working days
Our engineering team investigates the report
A fix timeline is shared if the issue is confirmed
A patch or mitigation is released
Credit may be given to the reporter if requested

Typical resolution window:

3 to 14 days depending on severity

Critical vulnerabilities are prioritized immediately.

Supported disclosure practice

We follow responsible disclosure principles:

• reports remain confidential during investigation
• fixes are released before public disclosure
• reporters are kept informed throughout the process

Security scope

This policy applies to:

Blumebyte HR web application
API endpoints
authentication workflows
data access controls
employee information protection mechanisms

Out of scope:

third party integrations not maintained by Blumebyte
misconfiguration outside the Blumebyte platform
social engineering attempts

Security best practices for contributors

If contributing to this repository:

• never commit secrets or API keys
• use environment variables for credentials
• validate all user input
• follow secure authentication standards
• keep dependencies updated
